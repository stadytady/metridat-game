# AGENTS.md

Инструкции для агентов и людей, которые меняют репозиторий. Обзор и команды — в [README.md](README.md).

## Проект

Головоломка на Godot 4.5 (GDScript, рендерер Compatibility). Правила — в `src/core/` (`RefCounted`, без нод).
UI — в `src/ui/`. Он только связывает правила с экраном, игровой логики там нет.

## Команды

```sh
tools/test.sh          # обязательно зелёный перед коммитом
tools/export.sh Web    # если менялись project.godot, export_presets.cfg или ресурсы
```

`test.sh` валит прогон на любом `SCRIPT ERROR`/`ERROR:`: в GDScript нет исключений, и ошибка в тесте иначе
выглядела бы как успех.

## Инварианты

1. **Каждый уровень решаем и не решён на старте.** Генератор только перемешивает решённое поле. Проверяет
   `test_levels_are_unsolved_and_solvable` (первые 30 уровней).
2. **Уровни детерминированы.** `Levels.seed_for(n)` и порядок вызовов `rng` в `Generator` не менять без причины:
   изменится уровень N у всех игроков, рекорды станут несопоставимы. Если менять, то осознанно и с записью в коммите.
3. **Число цветов простое и ≤ `Palette.CELLS.size()`.** Решатель работает над полем `Z_p`.
4. **`par` = минимум решателя.** Нажатия идут только вперёд, отмена одного нажатия стоит `k-1`.
5. **Web без потоков.** `variant/thread_support=false`, иначе сборка не стартует на GitHub Pages.
6. **Godot-версия одна везде**: `GODOT_VERSION` в `ci.yml`, `config/features` в `project.godot`, README.
   Обновлять вместе, шаблоны экспорта той же версии.

## Код

- Статическая типизация везде, где её понимает GDScript. Табы. Комментарии на английском и короткие, про *почему*.
- Новая логика — в `src/core/` с тестом в `tests/test_*.gd`. Метод теста начинается с `test_`, наследуется от
  `tests/test_case.gd`, проверки через `check`/`check_eq`.
- Новый тест должен **падать** на сломанной реализации: временно сломай код и прогони.
- Коммитить `*.uid` и `*.import` (Godot 4.4+). Не коммитить `.godot/` и `build/`.
- Ассеты и механики только свои, без копирования существующих игр.
