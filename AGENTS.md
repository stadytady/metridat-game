# AGENTS.md — Panticapaeum

Инструкции для агентов и людей, которые меняют этот репозиторий. Обзор для игроков и короткий статус — в [README.md](README.md); всё устройство — здесь.

## Команды (из корня репозитория)

```sh
tools/check.sh           # всё перед коммитом: импорт + lint + unit + сценарии + --walkthrough
tools/test.sh            # то же без lint; отчёт — build/qa/index.html (SCENARIOS="a b" — только эти)
godot --headless --path . --fixed-fps 60 -- --qa=<name> --qa-out=DIR   # один сценарий
tools/qa_shots.sh DIR [name ...]  # сценарии с рендером: кадры shot() в отчёт (RES=1280x800 — Deck)
tools/shots.sh DIR       # если менялся вид: посмотреть кадры, а не верить коду (RES=1280x800 — 16:10)
                         #   --only=workshop,ui --lang=ru --time=0..1 --lamps
                         #   --at=x,z --yaw=90 [--pitch=30 --name=x] — кадр из любой точки, без правки viewpoints
tools/build_assets.sh    # после правки gen_assets.py или Props; результат коммитить
tools/export.sh windows  # если менялись project.godot, export_presets.cfg, ресурсы

# Контент — не руками, а инструментами (те же вещи есть в меню редактора: проект → Tools)
godot --headless --path . -s res://tools/new_find.gd -- --id=<id> --title-en=… --title-ru=…
godot --headless --path . -s res://tools/new_key.gd  -- --key=UI_X --en=… --ru=…
godot --headless --path . -s res://tools/lint_content.gd   # отчёт отдельно от тестов
```

## Инварианты

1. **Высоты только из `Topo`.** Рельеф, мощение, дома и пропсы берут высоту из `Topo.terrain/surface/street_height`. Рельеф под мощением утоплен, а коллайдер дорожки шире мощения на `margin`, иначе край мостовой становится ловушкой. Проверяют `test_topo.gd` и проход.
2. **Обход вершин.** `MeshKit.tri/quad` принимают вершины против часовой стрелки, если смотреть снаружи. Новый примитив покрывай `test_geometry.gd`.
3. **Большие полигоны режутся** (`MeshKit.max_edge`), иначе аффинные текстуры плывут. Для геометрии за туманом ставь `max_edge = INF`, иначе число треугольников взлетит.
4. **Маршрут проходим.** Всё, что ставишь на пути (скамьи, пропсы, стены), не должно перекрывать проход: `--walkthrough` должен оставаться PASS. Новую находку добавляй в `_route()` в `director.gd` (строка `id`), NPC — шагом `"talk:<npc_id>"`. После последней находки бот идёт обратно и зажигает светильники: новый светильник должен быть в пределах досягаемости с обратного маршрута.
5. **Находка = `data/discoveries/<id>.tres` + `scenes/interactables/<id>.tscn` + строки `D_<ID>_*` в `strings.csv`.** Включая `D_<ID>_HINT` для журнала: подсказка, где искать, а не точные координаты. Модель находки — в `Discovery.model` (её ставит на карту `Inspectable` и показывает витрина `ItemViewer`); у новой модели проверь кадр `tools/shots.sh DIR --only=finds`. В `history` только установленные факты, и у каждого источник в `sources`. Страницы вымысла у находок нет (поле `narrative` убрано, `test_finds_carry_no_fiction`): выдуманные истории к вещам не пишутся. Если сам предмет частично реконструирован (точный текст стелы), это одна нейтральная фраза в `description`; люди и места вокруг находок, придуманные игрой, перечислены в README («Правда и вымысел») и закрыты общей сноской `UI_FOOTNOTE`/`UI_CREDITS_4`. Находка сна — с `epilogue = true`: не входит в счёт и в ход вечера. Создавай не руками: `tools/new_find.gd` или «Новая находка…» в плагине `addons/dev_tools` пишет `.tres`, `.tscn` и все четыре строки сразу, с кавычками где нужно; дальше остаётся заполнить тексты и источники.
6. **PS1-ограничения.** Текстуры до 128 px, ограниченная палитра, nearest, без мипмапов. Никакого PBR, normal map, SSAO/SSR/glow. Новые поверхности — через `psx_*` шейдеры, материалы генерирует `gen_assets.py`. Прозрачность — только alpha-test (`psx_cutout`: сети, тонкая ткань), без смешивания. Альфа цвета вершин у `psx_lit` — это доля фонового света (`AO = COLOR.a`, `AO_LIGHT_AFFECT = 0`): 1 под открытым небом, мало — в глубине гробницы; прямой свет (солнце в проём, лампа) она не трогает. Поэтому `kit.color = Color.WHITE * k` без `kit.color.a = 1` затемнит фон на этой поверхности — после умножения альфу возвращай.
7. **Ввод мира — через `Input`/`Main._input`.** Мир живёт в `SubViewport` без input events, `_unhandled_input` внутри мира не сработает.
8. **Тексты только через ключи.** Любой видимый игроку текст — ключ из `data/i18n/strings.csv` с переводами `en` и `ru`; строки с подстановкой — `tr("KEY") % ...` и перерисовка по `NOTIFICATION_TRANSLATION_CHANGED`. Проверяет `test_i18n.gd`; ключи диалогов — `test_dialogue.gd`. Новую строку добавляй `tools/new_key.gd` или пунктом «Добавить текст…» в плагине: он сам закавычит запятые и откажется писать `ru`, совпадающий с `en`.
9. **Взаимодействие — по контракту, а не по типу.** Луч `Interactor` берёт ближайший узел вверх по дереву, у которого есть `interact()` и `get_prompt()`, и опционально `can_interact()`. Так устроены находки, светильники и NPC. Новый интерактивный объект реализует эти методы, а не добавляет ветку в `Interactor`. Коллайдер — `collision_layer = 3` (слои 1 и 2: мир и луч взаимодействия). Панель при закрытии вызывает `Game.mark_ui_closed()`: после этого E 0,4 с не действует на мир, иначе игрок застревает в предмете.
10. **NPC = `Npc` + `Figure`.** Персонаж собирается из сегментов `Figure.RIG`; поза — запись в `POSES` и `SEAT` (наклон корпуса и головы вперёд — отрицательный X), анимация — `Figure.motion`, квантованная до 15 кадров/с. Реплики — ключи `NPC_<ID>_<N>` и `LOC_*`. Всё, что говорит NPC, — вымысел; на экране это больше не помечается, поэтому исторические факты — только в находках. Диалог — ресурс Dialogue Manager (аддон `addons/dialogue_manager` 3.9.1) в `Npc.dialogue`, файлы в `data/dialogues/*.dialogue`; текст в них ключами, выборы и переходы считает аддон. Списков реплик в коде больше нет: у каждого говорящего NPC свой `.dialogue`. Исторические факты не кладутся в реплики: им место в находке рядом, с источниками. Люди помнят, что игрок нашёл: у каждого говорящего есть выбор `- LOC_<NPC>_CHOICE_SAW [if Game.has_found("<id>")]` последним в списке (бот по умолчанию берёт первый, и обход от этого не меняется); id — находка города, не сна, `test_dialogue` это проверяет, сценарий `remembered` проходит такой разговор. Животные (`Chicken`) — без коллайдера и в пределах своего `home`/`radius`, чтобы не перекрывать маршрут. Работа NPC — обход `patrol`: у каждой точки своя поза (`patrol_poses`), пауза (`patrol_pauses`, 0 — пройти не останавливаясь) и направление взгляда (`patrol_faces`, нужно, чтобы сесть лицом куда надо). Реквизит вешай на сигналы `reached(i)` (пришёл, например охапка дров у подмастерья) и `departed(i)` (уходит, например лепёшка у Мирто), а не на таймеры. С занятыми руками ставь `carrying`: при ходьбе руки остаются в позе `carry_pose` (`carry` или `head_carry` для гидрии на голове). Маршрут по мощению, которое идёт под уклон, — с `follow_ground`, иначе ноги уходят в камень или висят. Кто занят у точки с заданным `patrol_faces`, к игроку корпусом не поворачивается. Остановившийся на ходу стоит или держит ношу, а не садится в свою домашнюю позу. Сидящий (`seated()`) к игроку поворачивает только голову, иначе ноги уйдут в сиденье. Маршрут, который ходит рядом с путём бота, держи константой в районе и проверяй тестом, как `Workshop.BOY_ROUTE` в `test_chores.gd`.
11. **Время суток — одно число.** Свет, небо, туман и море зависят только от `DayCycle.sample(t)`, а `t` — от числа находок (`Game.time_target()`). Не задавай энергию солнца или цвет неба напрямую в районах. Исключение — витрина `ItemViewer`: у неё свой мир и постоянный свет, чтобы находку было видно ночью. За ночью лежит сон: `DayCycle.DREAM` (1.25), туман задаётся ключами (`fog_begin`/`fog_end`), а не в коде районов. Свой свет города (лампы у дверей, жаровни, окна, фонарь пристани) зажигается от одного порога `DayCycle.LAMPS_ON` — сейчас на тринадцатой из девятнадцати (`LAMPS_ON_AT_FIND`); свой порог району не заводить, `test_day_cycle` это проверяет. Погода — второе число рядом с часом: `Weather.now(t)` → `(rain, storm)` от `Game.weather_seed` (сид берётся при новой прогулке и живёт в сохранении; 0 — сухо, его получают автоматика, кадры и трейлер), и `Atmosphere` пропускает `DayCycle.sample(t)` через `Weather.apply()`, которая только гасит солнце и сгущает серую дымку, не двигая солнце и небо по часам; ливень или шторм один, днём, к сумеркам кончается, каждая третья прогулка сухая (`test_weather`). Вспышка молнии — тоже через `Atmosphere` (`Weather.lit_by_bolt`), а не свой свет в районе. Новый источник огня — через `Lamp` (`lamps.gd`) или с явным `flicker.gd`; ночную проверку прохода (`_check_night`) не ослаблять.
12. **Ассеты детерминированы.** Новая текстура или звук в `gen_assets.py` — отдельным вызовом в конце `main()` со своим `default_rng(<следующий seed>)` (сейчас занято до 559). Не вставляй её в список `TEXTURES` и не бери общий `rng`: сдвинутся seed'ы и перегенерируются уже закоммиченные файлы. Новые палитры и помощники в `gen_assets.py` — с новыми именами: модуль один, и переопределённый `GOLD` или `TERRA` молча перекрашивает уже закоммиченные текстуры (на `TERRA` так перекрасилась черепица). `.import` пишется только если его нет, иначе Godot сменит UID. После `build_assets.sh` в `git status` должны быть только новые файлы и то, что ты правил намеренно. Исключение — правка существующего генератора: шаги берут общий `rng`, а `fire.wav` пишется сразу после них из того же потока, поэтому `step()` обязан сохранять порядок и число вызовов `rng` (частота удара берётся от `idx`, а не через `rng.uniform`); проверка — прогнать аудио-часть `main()` и убедиться, что `fire.wav` не изменился.
13. **Оригинальность.** Ассеты, механики и тексты свои. Не копировать существующие игры и не тащить ассеты без явной лицензии.
15. **Надписи — рисованные, не шрифтовые.** Греческие надписи (имя города на титуле) идут через `GreekType`: глифы — полилинии в единичном боксе `BOX`, ширина слова — сумма `advance()` по каждой букве (иначе узкая йота встаёт на широкую базу и слово разъезжается). Файл шрифта не добавлять: сторонний TTF тянет лицензию и не даёт греческого с кириллицей в одном лице. Межбуквенный просвет считается от **краёв штрихов** (`glyph_span`, `ink_spans`), а не от бокса: у Ι бокс широкий, а чернила — одна черта, и перед ней зияла дыра (`test_the_ink_is_evenly_spaced`). Рисует `GreekType.draw()`: тень, светлая кромка (свет на краю резца), штрих, засечки на концах у верха и низа (`serif`) и `count` — сколько букв уже высечено. Новую надпись проверяй через `missing()` и `test_greek_type` (штрихи в боксе, у буквы есть штрихи, ширины пропорциональны, просветы равные). Обычный текст интерфейса — по-прежнему ключи.
16. **Дом со входом — `Arch.cottage`, а не `Arch.house`.** `house()` — сплошной блок с коллайдером, внутрь не войти. `cottage()` оставляет проём в передней стене (`COTTAGE_DOOR` × `COTTAGE_DOOR_H`), кладёт пол с сохранившейся верхней гранью (срезанная грань = дырка, через которую видно море), поднятый на `FLOOR_LIFT` над цоколем — две грани на одной высоте мерцают, — потолок и ступени от порога к земле. Хозяйку в комнате одевает её облик в `Figure.LOOKS` (`woman`, `kerchief`, `skirt: "long"`): платок, волосы из-под него, хитон до земли. Женскую одежду не прикручивай к суставам коробками поверх фигуры — стоя и на ходу они читаются как ящик на бёдрах; `test_women_are_dressed_by_their_look` это ловит. Она прядёт (поза `spin`): прялку держит `Spindle.hold_distaff()`, а само веретено — отдельный узел `Spindle`, не дочерний к руке. Он каждый кадр встаёт под `Spindle.right_hand()`, чтобы нить висела отвесно при любом повороте руки. Длину нити и поворот задают `Spindle.drop/turn(t)`, их проверяет `test_spindle.gd`. Ночной фонарь у двери — `WallLamp` (группа `wall_lamp`, порог `WallLamp.DUSK`); `_check_night` в обходе падает, если хоть один остался тёмным. Фоновые дома города трогать не нужно: выбирай один и делай его коттеджем.
14. **Достижение — это id, два ключа и предикат.** id — он же API-имя в Steamworks (`ACH_*`): переименование сломает уже выданное у игроков. Добавляя достижение, трогай четыре места: запись в `Achievements.LIST`, пару `*_NAME`/`*_DESC` в `strings.csv` (через `new_key.gd`), чистую функцию рядом с `satisfied()` в `achievements.gd` и тест в `tests/test_achievements.gd`, который падает на неверном пороге. Steam — только через `Achievements.backend` (`unlock_achievement(id)`), никаких прямых вызовов SteamAPI в игровых скриптах. Обход проверяет, что маршрут заработал свои достижения: если новое бот не берёт — это должно быть осознанным решением, а не забывчивостью.
17. **Поручение — запись в `Quests.LIST`, ветка в `.dialogue` дающего и `QuestItem` в районе.** Просьба — выбор `- LOC_Q_<X>_ASK [if Game.quest_offered("<id>")]` с `do Game.take_quest("<id>")`, благодарность — первым условием в `~ start` (`if Game.quest_ready("<id>")` → `do Game.complete_quest("<id>")`), до обычного начала разговора. Ключ выбора — поле `ask` в `LIST`: по нему бот выбирает просьбу. Состояние меняет только `Quests.next_state` через `Game`; флаги в обход не заводить. Вещь ставь `District.spawn_quest_item()` с высотой из `Topo` и не за сетью или стеной: луч бьёт в первый коллайдер. `QuestItem` живёт на слое 2 (только луч, `Interactor` его маску расширяет), чтобы не перекрывать маршрут, и выключает коллайдер, пока скрыт. В `_route()` — шаги `take:<id>`, `pick:<id>`, `give:<id>`; `test_quests.gd` сверяет `.dialogue` со списком.

## Код

- GDScript со статической типизацией, табы. Комментарии на английском, короткие, про *почему*.
- Новая логика по возможности статической функцией (`Topo`, `Arch`, `Props`, `DayCycle`, `Figure`) с тестом.
- Новый район — наследник `District` в `scripts/world/`, узел в `world.tscn` и точка обзора в `World.viewpoints()` для `--shots`.
- Тест должен **падать** на сломанной реализации: временно сломай код и прогони.
- Плагин `addons/dev_tools` — только для редактора: игровой логики в нём нет, из экспорта он исключён (`exclude_filter`). Контент он пишет теми же функциями, что и `tools/*.gd`, чтобы у людей и агентов был один путь.
- Фоновая степь за холмом — `scripts/world/steppe.gd`: сухая трава, курганы, овцы. Всё вне маршрута; коллайдеры только у загона и у курганов (карман Царского кургана сделал часть из них досягаемой), овца не должна выходить за свой радиус. Курганы — круглые насыпи того же профиля, что у Царского (`mound_height`/`mound_profile`, 24 грани, материал `steppe`), три дальних — силуэты на горизонте; на двух ближних — каменные бабы (`Props.stone_woman`, лицом к городу). Пучки травы — `Props.tuft()`: три узкие травинки веером с двух сторон (квадратные карточки вблизи читались тёмными ящиками), оттенок соломы — `shade`. У холма степь гуще: `_near()` — пучки, сухие кусты, камни, только на открытом месте (`_open()`: не на террасе и в парке, не на курганах, не у Царского кургана); у курганов и у `_near` свои сиды (5480, 5481), поэтому трава и стадо до них не сдвигаются.
- Отладочное меню — `scripts/ui/admin_panel.gd`, клавиша `~` (экшен `admin`, `KEY_QUOTELEFT`). Оно читает `World.viewpoints()`, `Game.time_override` и `Game.weather_override` (вкладка «Погода»: как выпало прогулке, сухо, ливень, шторм — `WEATHER_STEPS`), поэтому новые точки обзора и часы попадают туда сами; отдельного списка не заводить. В легенду клавиш его не добавлять: это инструмент, а не управление. Тестами проверяются шаги часов (монотонные, в пределах суток) и что у каждого места есть имя.
- Парк — `scripts/world/park.gd`: с каждой стороны длинная дорожка, поперечные и внешняя (кольцо), девять рядов олив, кипарисы и фигуры. Роща пишется в один `MeshKit` — `Props.olive_tree(kit, seed, xf)` принимает трансформацию; отдельными узлами сотня деревьев съест отрисовки. Деревья не ставятся руками: `tree_spots()` сажает ряды и пропускает место у дорожек (`walk_clearance`), у фигур (`FIGURE_CLEAR`) и у скамей (`BENCH_CLEAR`). Новую дорожку добавляй в `walks()` — её увидят и деревья, и тесты. Калитки в парапете вырезает `hilltop.gd` (сегмент не строится, `rng` не трогается), ступени под ними — там же. Новую фигуру добавляй в `Park.FIGURES` (с поворотом для северной стороны, южная зеркальна); тесты читают именно этот список и проверяют, что фигура смотрит на дорожку, а не в кусты.
- Боковые улицы — `scripts/world/backdrop.gd`, фасадные детали — `Arch.house()`. Дом стоит полом на земле у своего фасада, а не на самом высоком углу участка: иначе дверь висит над переулком. - Дождь — `scripts/world/weather.gd` (`Weather`, узел в `world.tscn`): частицы-штрихи в коробке `BOX` вокруг камеры (без смешивания), ветер с моря порывами — `drift(t)` по `Sea.ONSHORE` (`gust()` — чистая функция). Ветер входит в **скорость** капли (`fall_velocity()`: вниз `FALL` плюс снос), а штрих — два скрещённых узких квада вдоль y (`streak_mesh()`), выровненных по полёту (`particle_flag_align_y`), поэтому дождь косой: в ливень ~10–25°, в шторм ~20–45° (`slant_deg`, `test_the_rain_slants_with_the_wind`). Билборд `FIXED_Y` и ветер ускорением (`gravity`) не возвращать: штрих тогда стоит отвесно, хоть капля и летит вбок. Коробка рождается с наветренной стороны (`drift × lifetime / 2`), чтобы капли падали вокруг камеры. Вблизи штрихи гаснут дизерингом (`DISTANCE_FADE_PIXEL_DITHER`); густота — `amount_ratio` от силы ливня, звук `rain.wav` (seed 546) петлёй. Фикстура сценария — ключ `weather` (сид); сценарий `shower` ловит дождь и тусклое солнце на высоте ливня. Каждая четвёртая мокрая прогулка — шторм (`Weather.kind(seed)`: `DRY`/`SHOWER`/`STORM`): дольше ливня (`STORM_HALF`) и тоже кончается до сумерек, `storm_at()` — его доля. Погоду «сейчас» знает только `Weather.now(hour)` → `(rain, storm)`: она же учитывает сон, пролог и выбор отладочного меню (`Game.weather_override`, не сохраняется); `rain_at` в обход неё не звать. Шторм в `apply(k, rain, storm)` гасит солнце и сгущает тёмную дымку, ветер `drift(t, storm)` сильнее, волна выше — `Sea.swell` (её множат и `height_at()`, и `amplitude` шейдера; растёт медленно, `move_toward`), поэтому морские камни проверяются при `STORM_SWELL`. Молния — часы, а не состояние: окна по `BOLT_EVERY` секунд на `Weather.clock`, `bolt_time(n)` от номера окна, `flash(t, storm)` — вспышка (два импульса, шаг 15 кадров/с, только при `storm ≥ BOLT_FROM`), её `Atmosphere` накладывает через `lit_by_bolt()` на ambient и туман (плоская вспышка всего города, отдельного света нет), а гром — `thunders(t0, t1)` с задержкой `thunder_lag(n)`: те же окна, поэтому каждый удар слышен ровно раз. Звуки — `thunder.wav` (553) и петля `gale.wav` (554; `wind.wav` — это другой, тихий ветер холма). Атмосфера перерисовывается не только по часу, но и когда меняется погода или вспышка. Сценарий `storm` включает шторм через само меню (события `InputEventAction`: меню слушает `_input`, `Input.action_press` до него не доходит) и ждёт вспышку, `CAP_THUNDER` и рост волны.

Новая библиотека или ассет с лицензией — константа там же, строка на странице и проверка в тесте. Тексты лицензий не переводятся (`auto_translate_mode` выключен), остальное — ключи `UI_CREDITS_*`. Кадр — `ui_credits` в `--only=ui`.
- Лог прогулки для плейтестов — `scripts/core/session_log.gd` (`SessionLog`): заводит его `Main._start_saving()` только в живой игре (автоматика его не пишет) и до пролога, чтобы пролог попал в лог. Файл на сессию в `user://sessions/`, хранится `KEEP` последних; каждая строка `секунды\tсобытие\tподробности\t@ x, y, z` сразу сбрасывается на диск (окно закрыли — ничего не потеряно). События — с сигналов `Game` (находки, места, разговоры, поручения, лампы, пролог, сон, чеканка) и `Achievements`, плюс точка раз в `SAMPLE_EVERY` и стоянка дольше `STILL_AFTER` (`still`/`moved`). Ничего личного: версия, ОС, видеокарта, язык. В вебе лога нет (`supported()`): из браузерного `user://` файл не достать. Кнопка в паузе «Открыть папку с логами» (`UI_OPEN_LOGS`). Новое событие игры, которое важно для плейтеста, — строка `write()` на его сигнал. Тест — `test_session_log`.
- Титульный экран — `scripts/ui/title_screen.gd`: виньетка и тёмная полоса под надписью (градиенты, не панель), меандр — `GreekTitle` — подзаголовок `UI_TITLE_SUB` — меандр, меню словами (`_item()`: без рамки, выбранное — золотом между двумя ромбами `_draw_mark`, наведение мышью = выбор, поэтому выбранный пункт всегда один). Пункт «Титры» (`UI_TITLE_CREDITS`) открывает страницу авторов паузы отдельно: титул прячется, но держит игру (`_away`, `is_open()` остаётся true), `Main` связывает `credits_requested` → `PauseMenu.open_credits()` и `credits_closed` → `back_from_credits()`; «Назад» и Esc в этом режиме закрывают паузу без захвата мыши и без `closed` (`test_the_title_opens_the_credits_and_gets_them_back`). Текст пунктов — заглавными из общих ключей (`_label()`, ключ в мете `key`, перерисовка по `NOTIFICATION_TRANSLATION_CHANGED`), «Выйти» в вебе скрыт. При открытии играет `_play_intro()` (меандр от середины, буквы по одной через `GreekTitle.reveal`, потом подзаголовок и меню); первое нажатие только доигрывает его (`finish_intro()`), иначе игра стартует под недорисованным титулом. Кадры и тесты зовут `finish_intro()` сами. Кадр — `ui_title` в `--only=ui`.
- Версия — `application/config/version` в `project.godot`: её показывают титульный экран (угол, узел `Version`), страница авторов, лог и замер. Сборка релиза сама вписывает номер тега (шаг «Stamp the version» в `release.yml`); в репозитории держи номер последнего релиза — `test_session_log` сверяет его со ссылкой «Скачать» в README.
- Громкость — `Game.master_volume` (0..1) → `Game.apply_volume()` на шину Master, ползунок в `pause_menu.gd`; новые настройки добавляй так же: поле в `Game`, чтение и запись в `load_settings`/`save_settings`, строка в паузе.
- Удобство — три настройки в паузе (вторая колонка: одна колонка с текстом 140 % не влезала в 1080). «Покачивание камеры» — `Game.head_bob`: и качание при шаге, и расширение обзора на бегу идут через `Player.camera_motion()`, новый эффект камеры умножай на неё же. «Размер текста» — `Game.text_scale` (1,0–1,4): размер шрифта ставит только `UiStyle.font(c, size)` (через неё же `label()` и `button()`), она запоминает базу в мете `ui_font`, и `UiStyle.rescale(root)` перерисовывает всё сразу; `add_theme_font_size_override` вне `UiStyle` ловит `test_accessibility`. Кадры: `tools/shots.sh DIR --only=ui --text=1.4`. «Подписи к звукам» — `Game.captions`: источник звука зовёт `Game.caption(key, pos, reach)`, а та сама решает, показывать ли (включено, слушатель ближе `reach`, тот же ключ не чаще `CAPTION_GAP_MS`), и шлёт `caption_requested`; HUD рисует строку над полосой клавиш. Ключи — `CAP_*` (голоса переулков — `StreetVoices.caption_key(kind)`); новый заметный звук — свой `CAP_` и вызов рядом с `play()`.
- Управление — `scripts/core/keys.gd` (`Keys`): клавиши по умолчанию (`DEFAULT_KEYS`, их можно переназначить), неподвижные (`FIXED_KEYS`: стрелки, Esc, `~`, F3), кнопки и оси геймпада (`PAD_BUTTONS`, `PAD_AXES`). Новое действие — запись в эти таблицы, а не `InputMap.add_action` в своём скрипте. Esc и B — экшен `back`: им закрываются панели; `pause` (Esc, START) только открывает паузу, иначе B на геймпаде открывал бы меню посреди города. Переназначение — `Game.bind_key()` → `Keys.rebind()` (занятая клавиша меняется местами), хранится в `[keys]` настроек. Видимый текст не пишет клавишу буквой: `[{use}]`, `[{back}]`, `[{journal}]`, `[{goals}]`, а подписи показываются через `Keys.bind(label, key)` или `Keys.fill(tr(...))` — они перерисуются при смене клавиш, языка и устройства (`Game.device_changed`, `Game.pad`). `test_controls` ловит строку с буквальным `[E]`. Тест, который трогает настройки, переводит `Game.settings_path` во временный файл: иначе он перезапишет настройки игрока.
- Сохранение — `scripts/core/save_game.gd` (`SaveGame`, `user://save.cfg`): `snapshot()` → `write()`, `read()` → `apply()`. Пишет его только `Main` и только в живой игре (после «Начать»/«Продолжить»; автоматика не пишет никогда): на находку, поручение, лампу, раз в `AUTOSAVE_SECONDS` и на выход, кроме пролога и сна. Восстановление тихое: `apply()` ставит состояние в `Game` и шлёт `Game.state_restored`, а не `discovered`/`lamp_lit` (иначе откроется панель находки и посыплются тосты). Новое состояние, которое должно переживать выход, — поле в `snapshot()`/`apply()` и слушатель `state_restored` у того, кто его рисует. Лампа узнаётся по месту (`lamp_key`), не по номеру. Меняешь формат несовместимо — подними `VERSION`: старое сохранение тогда не читается, а не ломает игру.
- Раскладка интерфейса — от `UiStyle.screen(node)` (холст при `stretch/aspect = expand`: 1920×1080 на 16:9, 1920×1200 на Steam Deck, 2560×1080 на 21:9) и `UiStyle.centred(node, size)`, а не от литерала 1920×1080: `test_hud` не пускает его в `scripts/ui`. Полноширинное — якорями (`PRESET_TOP_WIDE`), не шириной 1920. `ScrollContainer` в панели, которую ужимает `reset_size()`, сам высоты не просит: задай ему `custom_minimum_size.y`, иначе список схлопнется (так было с журналом). Новую панель смотри `RES=1280x800 tools/shots.sh DIR --only=ui` и в 2560x1080.
- QA-сценарии — `tests/scenarios/<name>.gd`, наследник `tests/qa/scenario.gd`: `fixture()` (ключи перечислены в базе, `test_qa` не пустит неизвестный) и `run()` с шагами `step("…")` и `check()`. Ходит он помощниками базы (`walk_to`, `inspect`, `talk`, `take/pick/give`, `press`, `pad_button`), а это шаги обхода `Director`: своего бота не писать, иначе сценарий и обход разойдутся. Фикстура ставится через `SaveGame.apply`, поэтому новое состояние, которое переживает выход, сразу доступно и сценариям. Новая механика — короткий сценарий из середины прогулки рядом с unit-тестом, а не ещё одна ветка в `_route()`. Сценарий должен **падать** на сломанной реализации, как и тест. Кадры — `shot("имя")` (headless пропускается; `tools/qa_shots.sh` и задача `qa-shots` в CI гоняют с рендером), встать в точку обзора — `view("watch")`, посмотреть на фигуру — `look(pos)`. Камеру ставь туда, где заведомо пусто (путь, по которому только что прошёл NPC), а не «на 4 м позади»: там бывает герм. `seconds()` считает **игровое** время, а с `--fixed-fps` раннер CI крутит кадры быстрее реального: всё, что ждёт настенных часов (`Game.can_interact_now()` и `REARM_MS`, тосты на `Time`), жди по `Time.get_ticks_msec()` — иначе сценарий проходит на медленной машине и падает в CI (так было с `mint_coin`). Всё из `tests/` не экспортируется: `Main` загружает раннер по пути и только при `--qa=`.
- Пакеты Ubuntu в CI — только `tools/apt-cached.sh <пакеты>` под шагом `actions/cache` с путём `~/.cache/apt` (ключ с месяцем): тёплый кэш ставит без сети (`--no-download`), холодный идёт на зеркало с дедлайнами и повторами — зеркало иногда висит по 15 минут, на этом падал экспорт. Голый `apt-get` в workflow не писать.
- Материалы GLB-моделей подменяются нашими по имени (`Mats.apply_to` → `material_key()`); экспорт glTF переименовывает материал, совпавший с именем узла (`cypress` → `cypress2`), поэтому числовой хвост отрезается. Без этого поверхность остаётся белой материалом импортёра (так было с кипарисами склона и статуэткой); `test_models` проверяет, что у каждой поверхности каждой модели наш материал.
- Коммитить `*.uid` и `*.import`. Не коммитить `.godot/` и `build/`.
- Документация на русском, код и коммиты на английском.
- Не выдавать непроверенное за проверенное. Таблица «Статус проверки» в README отражает реальность.

### PS1-конвейер

| Приём | Где |
|---|---|
| 3D рендерится в `SubViewport` в 720 строк: 1280×720 для 16:9 (`INTERNAL_HEIGHT`, `Main.render_size`) и растягивается в 1,5 раза на 1080p (2 на 1440p) с выборкой sharp bilinear в `psx_post`: пиксель ровный, шов мягкий на один экранный пиксель | `scenes/main.tscn`, `scripts/core/main.gd` |
| 15-битный цвет (31 уровень на канал) с упорядоченным дизерингом Bayer 4×4 в низком разрешении | `assets/shaders/psx_post.gdshader` |
| Вершины привязаны к сетке низкого разрешения (дрожание полигонов) | все `assets/shaders/psx_*.gdshader`, глобальный `psx_resolution` |
| Аффинное текстурирование, с ослаблением на рельефе и мощении | `psx_lit.gdshader`, `affine_amount` в материалах |
| Большие полигоны режутся на ячейки ≤ 3 м, иначе аффинное искажение «плавит» плиты (так делали и на PS1) | `MeshKit.max_edge` |
| Текстуры 64×64 и 128×64, палитра 5–8 цветов на текстуру, ordered dither, nearest, без мипмапов | `tools/gen_assets.py` |
| Flat shading, Lambert без бликов, тени с жёстким фильтром (в низком разрешении они получаются ступенчатыми) | `MeshKit`, `atmosphere.gd` |
| Линейный depth fog: море уходит в дымку горизонта | `atmosphere.gd` |
| Море: сетка 4 м у берега и крупнее к горизонту; 4 направленные волны с дисперсией глубокой воды и обмелением у берега; плоские грани ловят солнце; барашки и полосы прибоя к реальной линии берега (`Topo.waterline_x`), края пены дизерингом | `psx_water.gdshader`, `sea.gd` |
| Небо — расписная панорама полосами без фильтрации | `sky.png`, `PanoramaSkyMaterial.filter = false` |
| Лампы в окнах: свой шейдер мерцания, у каждого окна своя фаза в альфе вершин, шаг 15 кадров/с | `psx_lamp.gdshader`, `Arch.lamp_phase` |
| Фигуры-призраки растворяются без полупрозрачности: пиксели отбрасываются по шуму с порогом `fade`, шаг 15 кадров/с | `psx_ghost.gdshader`, `Apparition` |
| Огонь — квадратные частицы с 15 FPS | `scenes/environment/altar_fire.tscn` |
| UI в нативном разрешении: плоские панели с жёсткой рамкой, шрифт без сглаживания | `scripts/ui/` |

PS1-эффекты отключаются в меню паузы: это удобно для сравнения и при проблемах с читаемостью.

### Трейлер, замер, релиз

- Трейлер — `tools/trailer.sh out.mp4` (1280×720, 30 FPS, без PS1-эффектов; `SIZE=1920x1080` — 1080p, `PSX=1` — в игровом виде). Планы — `scripts/core/trailer.gd` (границы планов сведены с музыкой — меняй содержание плана, а не его время; план может задать погоду ключом `weather`, тогда часы молнии ставятся так, чтобы вспышка попала в план, а волна сразу штормовая; `--benchmark` летит тем же путём). Снят в самой игре Movie Maker'ом (на машине без GPU — lavapipe + Xvfb).
- ``` Panticapaeum.exe -- --benchmark ```  Камера 10 секунд летит по маршруту трейлера в реальном времени, с выключенным vsync и без ограничения FPS. Первые 0,5 с не считаются: в это время компилируются шейдеры. В конце на экране и в файле `%APPDATA%\Godot\app_userdata\Panticapaeum- Echoes of the Bosporus\benchmark.txt` появятся GPU, средний FPS, 1%-low и худший кадр. Во время обычной игры то же показывает F3.
- Релиз — Actions → `release` → Run workflow с тегом (`v0.0.N`): тег создастся сам. Текст релиза — в `.github/workflows/release.yml` («New in vX»), обнови его, ссылку «Скачать» в README и `config/version` в `project.godot` до запуска (номер в сборку workflow впишет и сам, но тест сверяет репозиторий). Пакеты локально: `tools/package.sh vX`, `tools/smoke.sh`.
